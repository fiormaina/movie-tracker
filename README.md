# Movie Tracker

Movie Tracker — проект для отслеживания фильмов и сериалов, которые пользователь смотрит или планирует посмотреть.

Идея проекта — собрать в одном месте личную коллекцию: избранное, списки, статусы просмотра и заметки. Отдельная часть проекта — браузерное расширение, которое в будущем должно помогать определять просмотр на стриминговых платформах.

```text
